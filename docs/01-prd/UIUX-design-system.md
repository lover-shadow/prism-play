## 1. 核心定位与设计哲学 (Visual Theme & Atmosphere)

《光影Play》（Prism Play）定义为**“沉浸式私域流媒体工业级终端”**。彻底颠覆市面上充斥着广告弹窗、劣质网页套壳、粗暴 AI 模板的聚合器形象，向 **Apple TV+、Netflix、HBO Max、Linear** 的顶级克制质感看齐。

### 视觉三轴刻度定调
- **设计寄存器**：**Product 寄存器**（设计绝对服务于短剧/电影内容本身，不喧宾夺主，赢得克制专业感）；
- **DESIGN_VARIANCE (5/10)**：结构高度自洽稳定，非对称仅用于首屏黄金置顶续播位与榜单微流；
- **MOTION_INTENSITY (4/10)**：克制流畅，功能性微交互为主（150ms 胶囊反馈，240ms 抽屉推入），零冗余动画；
- **VISUAL_DENSITY (6/10)**：紧凑且层次分明，4px 阶梯网格，专为移动端单手刷剧排布。

### P0 绝对红线审查（零容忍退回项）
1. **绝对禁止 emoji 充当功能图标**：严禁出现任何系统 emoji 字符作为 UI 按钮图标。全系统统一锁定 **Lucide Icons 纯 SVG 矢量方案（Stroke 2.0px，统一 16/20/24px）**；
2. **绝对禁止紫色→粉色渐变主视觉**：严禁 `linear-gradient(135deg, #7C3AED -> #EC4899)` 及发光边框 + 廉价毛玻璃三位一体套路。选用电影胶片级**琥珀金 (Amber Gold `#E5A93C`)** 作为唯一强调色，每屏可见强调色使用严格 ≤ 2 处；
3. **绝对禁止硬编码颜色**：100% 样式走 Design Token 系统（`var(--token)`），确保日夜双模 0 成本切换。

## 2. 矢量图标系统规范 (Lucide SVG Specification)

全工程统一使用精细工业级 SVG 图标方案，杜绝乱象与杂质。

### 2.1 规范参数
- **图标基准源**：Lucide Icons
- **视口定义**：`viewBox="0 0 24 24"`
- **笔触样式**：`stroke-width="2"`，`stroke-linecap="round"`，`stroke-linejoin="round"`，`fill="none"`，`stroke="currentColor"`
- **三级固定尺寸**：
  - **16px (`icon-inline`)**：行内微标、集数状态、角标（如高清指示、小箭头）；
  - **20px (`icon-button`)**：顶部导航按钮、次级操作胶囊、播放器轻控制按钮；
  - **24px (`icon-standalone`)**：底部主 TabBar、播放/暂停大键、全屏锁。

## 4. 四模海报排版视觉规范 (Poster Grid Engine)

为满足不同年龄层与不同观影习惯的用户（年轻人极速翻找、长辈大图看字、收藏党高密检视），系统提供四种海报视界，并支持顶部一键平滑切换，状态持久化到本地存储。

### 4.1 四模详细参数规格

以下既有网格数值为历史设计基线；HP-10要求四种布局统一收紧横纵间距并以有效视口实测校准，不把本节旧间距作为新验收目标。具体最终值应由Token样稿与浏览器几何验证确定。

```
【模式一：中图紧凑 (3列 · 默认)】     【模式二：大图舒适 (2列)】
┌────────┬────────┬────────┐         ┌────────────────┬────────────────┐
│  海报  │  海报  │  海报  │         │                │                │
│  3:4   │  3:4   │  3:4   │         │    海报 3:4    │    海报 3:4    │
├────────┼────────┼────────┤         │                │                │
│剧名+4K │剧名+完 │剧名+全 │         ├────────────────┼────────────────┤
└────────┴────────┴────────┘         │ 剧名 + 题材标签│ 剧名 + 题材标签│
                                     └────────────────┴────────────────┘
【模式三：微缩书架 (4列)】             【模式四：图文列表流 (单列)】
┌────┬────┬────┬────┐               ┌────────┬─────────────────────────┐
│3:4 │3:4 │3:4 │3:4 │               │海报 3:4│ 剧集全称 · 4K超清完结   │
├────┼────┼────┼────┤               │ 88x117 │ 题材：逆袭 / 战神 / 都市 │
│剧名│剧名│剧名│剧名│               │        │ 简介：五年前他是落魄赘婿│
└────┴────┴────┴────┘               └────────┴─────────────────────────┘
```

1. **中图紧凑 3 列（默认推荐）**：
   - **移动端规格**：`grid-template-columns: repeat(3, 1fr)`，列间距 `12px`；
   - **海报长宽比**：严格 `3:4`；
   - **信息密度**：单行文本截断 + 右下角悬浮半透明微标（如 `4K超清`、`第68集`）；
   - **体验收益**：单手大拇指 1 秒快速纵览 9~12 部热播剧，选剧效率最高。
2. **大图舒适 2 列**：
   - **移动端规格**：`grid-template-columns: repeat(2, 1fr)`，列间距 `16px`；
   - **信息密度**：海报下展示剧名（15px 加粗）+ 次级题材标签（如 `逆袭` `战神`）；
   - **适用人群**：追求海报精致质感，或视力需要大字号的用户。
3. **微缩书架 4 列**：
   - **移动端规格**：`grid-template-columns: repeat(4, 1fr)`，列间距 `8px`；
   - **信息密度**：书脊式极度紧凑，仅展示海报与单行微缩文字（11px）；
   - **适用场景**：追剧狂人海量库检索、连载历史大盘点。
4. **图文列表流（单列）**：
   - **移动端规格**：单列横向卡片，左侧固定宽 `88px`（高 `117px`，维持 3:4）海报，右侧弹性布局；
   - **展示项**：剧名 + 核心题材胶囊 + 更新集数进度 + 两行剧情梗概（-webkit-line-clamp: 2）；
   - **适用场景**：重度剧情导向选剧，不光看脸还要看故事简介。

### 4.2 元数据与角标展示
- 卡片主分类维持真实 `category`；可信副标签单独展示，搜索索引词不能直接当标签。
- 摘要只显示真实来源文本，最多240 Unicode code points；无摘要时可显示明确来源年份、地区、语言（各自遵守公开API长度边界），没有可信信息就省略并压缩信息区。
- AI制作类型仅在 `isAi === true` 时标记“Ai剧”；该标签描述制作类型，不评价质量。缺字段不猜测、不显示占位标签。

### 4.3 响应式断点阶梯

| 设备断点视口 | 中图模式列数 | 大图模式列数 | 书架模式列数 | 图文列表列数 | 外边距 Padding |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **窄屏 (< 768px)** | **3 列** | **2 列** | **4 列** | **1 列 (单列)** | 旧设计间距值已废止；按 Tokens 与实际视口校准 |
| **平板/折叠屏 (≥ 768px 且 < 1024px)**| **4 列** | **3 列** | **6 列** | **2 列并排** | 间距需统一收紧并验证卡片可读性 |
| **桌面/电视 (≥ 1024px)** | **6 列** | **4 列** | **8 列** | **3 列并排** | 容器留白按Tokens与实际视口校准 |

## 5. 顶层视界拓扑与导航架构 (Navigation Architecture)

### 5.0 底部主导航栏（三轨 v2 三键）
底栏【精选】(`sparkles`) /【追剧】(`clock`) /【我的】(`user`)，24px Lucide SVG；精选内默认显示综合首页及后续四个真实公开频道。底栏背景承载区与内容一起收窄居中，安全区只计算一次，宽度与间距以真实视口校准，不沿用仅收窄按钮的旧规则。搜索为全屏Overlay；榜单返回关闭榜单优先。海报零分享入口，分享仅播放器内。

### 5.1 第一层：综合首页与真实公开频道
启动默认展示本地综合首页，之后顶部固定顺序为【精彩短剧】、【电影仓库】、【人文纪录】、【动漫】。综合首页是跨四个公开频道的本地视图，不是云端ChannelItem；后四项保留真实 `drama`、`movie`、`documentary`、`anime` 身份与各自分类，显示名称与云端契约协调。个人探索保持独立双准入，不进入固定导航、综合推荐或公开榜单。
### 5.1.1 独立私密入口：个人探索（非固定公开导航）
- 仅有效 **B/Y/S 高级授权**可在设置中看到开关；勾选先弹年满 18 岁与内容风险免责声明，明确确认后才进入；无权用户不可见开关或锁定频道占位；
- 当次开启状态仅存内存，冷启动、完全退出或退出会话一律关闭；任何时刻未同时满足高级授权与当次开启时，频道节点、二级分类、海报、播放源和分享入口均不得出现在 DOM；
- 服务端必须按“授权档位 + 当次会话”双条件过滤：未同时满足有效 B/Y/S 与有效 `X-Private-Session` 时，`/api/channels` 不返回 `private` 节点及二级分类，`/api/sources`、片单与取流接口一律不返回私密数据；当次凭据由 `/api/private-sessions` 签发且客户端只驻内存；
- 进入频道/播放时 Android 动态启用 `FLAG_SECURE`，退出关闭；私密内容禁写历史与断点、禁磁盘媒体缓存；任何个人探索内容均不渲染分享按钮，边缘 `/s/:id` 返回 404。

### 5.2 第二层：吸顶联动横滑次级胶囊
与第一层真实频道动态绑定；综合首页不虚构二级频道或来源分类。公开频道可有真实快捷榜与二级分类，点击规则、刷新和榜单范围按HP-06/07执行。
- **数据驱动的快捷胶囊**：`[今日爆火]` 仅在有过去 24 小时真实公开播放事件时出现；`[偏好推荐]` 仅在有本机公开偏好与可用标签时出现；`[最新上线]` 仅在内容具有首次公开时间时出现。缺相应数据即隐藏，不造假榜单与推荐；
- **题材无缝联动胶囊**：`[都市]`、`[战神]`、`[逆袭]`、`[甜宠]`、`[穿越]`、`[悬疑]`、`[科幻]`；
- **交互规范**：支持横向惯性滚动，滑动时隐藏系统滚动条，选中的胶囊背景赋予 `var(--surface-warm)` 且描边 `var(--accent)`。

### 5.3 首屏黄金置顶续播位 (Continue Watching Hero Card)
- **位置**：首屏第一视口顶部、横滑胶囊正下方；
- **卡片构成**：
  - 左侧/背景高斯模糊暗图：上一部观看短剧的封面；

1. **左侧垂直滑动（亮度调节）**：

## 8. Web H5 极简短剧分享落地页规范 (Zero-friction Share Flow)

专为朋友圈与微信私域裂变定制的传播页面，遵循“零废话、点开即播、播完截流”原则。

### 8.1 视觉动线与状态机
1. **单集尝试起播态**：
   - 手机浏览器/微信打开 `https://play.prismos.org/s/<drama_id>?ep=<ep>&ref=<code>`，仅加载 `ep` 指定的**当前单集**；私密 `drama_id` 在边缘网关直接 404，不返回播放页；
   - 视频容器使用 `var(--player-bg)`，无预先下载弹窗；内联 `playsinline` 自动尝试播放。浏览器拒绝自动播放时，保持当前集封面并展示带文字的“播放本集”按钮，由用户一次点击/键盘操作启动，不反复无手势重试；
   - 微信环境不得在 `/s/` 自动跳出或前置阻断播放；用户手动点击下载可展示“右上角在浏览器中打开”辅助蒙层，自动下载引导仅归 `/dl`；截流卡仍只在 ended 后出现。
2. **当前集播完截流卡片（Conversion Card）**：
   - **仅在当前集实际触发 `ended`** 后，将控件淡出（`var(--duration-normal)`）并显示 `var(--surface-raised)` 实色卡；暂停、缓冲、播放失败、切到后台均不得触发；
   - 卡片主标：`本集已播放完毕`；副标：`如果继续看，请下载【光影Play】`；
   - 核心 CTA：`下载安装【光影Play】`，使用 `var(--accent)` / `var(--accent-on)`，可点击区至少 44×44px；下载失败保留重试入口。

### 8.2 核心视图状态与输入契约
