# 新增内容轻量搜索与端侧播放实施计划 (精简务实版)

> **核心原则：** 抛弃一切过度工程与假想合规约束，只做真实流媒体必要链路。搜索只找卡片，点开才找分集ID，视频流由手机本地按需取流解密播放。完成一项勾选一项。

**Goal:** 拔除云端搜索的分集爬虫，压低在线读路径 CPU 与子请求消耗，实现"云端拉卡片、点开拉分集ID、手机本地取流解密"，并修复版本展示与播放器 UI 交互。

> **2026-10-08 结果口径：** Task 1～5、7 已落地并经 Master 真机验收随 v2.6.5 发布；"秒级出结果、零 503"作为目标**未达成**——免费档突发额度下同一查询可先 200 后 503，详见下方 Task 6.2 与 SPEC-CLOUD-REFACTOR §6.1.2。

**Architecture:** 
1. **云端搜索**：只向上游检索剧目卡片（标题、海报、简介、总集数），共享缓存并直接返回，不做逐集取流。CPU、时延及资源消耗以测量为准，缓存复用和必要限流保留。已有目录和可用地址不做全库重抓；既有安全与私密边界保持，不新增版权审核或卡密搜索门槛。
2. **云端详情**：用户点击剧目时，按需拉取该剧 `vid_list`，生成携带 `videoId` 的分集清单，不抓视频流、不解密。
3. **端侧播放**：用户点击单集，手机原生代码（`ProbeNativeResolver`）利用 `videoId` 直连上游，本地 AES-CTR 实时解密后由 `ExoPlayer` 硬件解码播放。
4. **端侧界面**：选季框归位至选集上方，手势 HUD 层级置顶并精简文案，页面添加 `no-referrer` 防盗链，设置页常驻显示版本号。

**Tech Stack:** TypeScript, Cloudflare Workers / D1, Capacitor 7, Android Java (ExoPlayer / Media3).
