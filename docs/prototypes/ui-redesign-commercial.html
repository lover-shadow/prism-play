《光影Play》首页 UI 架构重构核心决策看板
1. 根治“三层死板吸顶”

问题：Header (52px) + 频道栏 (50px) + 二级胶囊 (44px) 纵向堆叠，死区达 146px。
商业解法：Logo 与一级频道同列并轨（48px），二级胶囊微型化 (32px)，直接释放 66px 黄金高度。

2. 剔除“调试器”排版大按钮

问题：把 4 个排版切换按钮平铺在标题下方（占 78px），属于明显的调试面板思维。
商业解法：收敛为内容区右侧的精致三态微型分段图标 (22px)，将低频配置退居幕后。

3. 引入商业级 Hero 焦点画卷

问题：开屏即机械网格，无视觉焦点，像 CMS 资源后台。
商业解法：引入 16:9 渐变沉浸大卡（TOP 1 爆款置顶），配置“立即起播第1集”主按钮，极大提升点击转化率。

4. 黄金断点续播卡“悬浮轻量化”

问题：88px 笨重大灰框横插在中间，生硬截断视线。
商业解法：重构为 46px 极简悬浮微卡，琥珀金细线进度条 + 一触秒续，保留核心能力同时无感融入。
